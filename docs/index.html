TL;DR PoseBridge preserves action-relevant visual semantics during human pose estimation and bridges them to skeleton-text alignment, reducing semantic information lost by skeletonization without adding an independent RGB action-recognition branch.

Abstract

Zero-shot skeleton-based action recognition (ZSSAR) is commonly formulated as skeleton-text alignment, but this alignment begins only after raw visual observations have already been compressed into joint coordinates. PoseBridge targets the resulting skeletonization gap: action-relevant object, interaction, and pose-relative cues that are no longer explicit in the skeleton sequence.

We reinterpret intermediate human pose estimation (HPE) representations as pose-anchored semantic cues. These cues are preserved within HPE through hierarchical refinement and body-aware pooling, then transferred to ZSSAR through a skeleton-conditioned semantic bridge and semantic prototype adaptation. PoseBridge uses the same HPE process that produces skeletons, without an independent RGB action-recognition backbone or external object detector.

METHOD

Preserve semantics before they disappear

PoseBridge consists of two coupled stages: semantic preservation within HPE, followed by semantic transfer to zero-shot skeleton-text alignment.

01

Pose-anchored semantics within HPE

Hierarchical refinement carries fine-grained visual evidence from shallow HPE layers into deeper pose-structured features. Body-aware pooling then aggregates responses around the predicted body, while semantic alignment encourages the representation to retain action-relevant evidence.

02

Bridge HPE semantics to ZSSAR

The skeleton-conditioned semantic bridge lets the skeleton representation query temporal pose-anchored cues. Semantic prototype adaptation calibrates language prototypes toward the pose-semantic space while keeping text as the zero-shot anchor.

ANALYSIS

What does PoseBridge recover?

Pose-anchored features attend more strongly to action-relevant object and interaction regions, producing a more separable zero-shot feature space for motion-ambiguous actions.
