# PoseBridge Project Page

A lightweight static project page for:

**PoseBridge: Bridging the Skeletonization Gap for Zero-Shot Skeleton-Based Action Recognition**  
NeurIPS 2026

## Publish with GitHub Pages

1. Create a public GitHub repository, e.g. `posebridge`.
2. Upload `index.html`, `style.css`, and `script.js` to the repository root.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.
6. The page will become available at `https://<username>.github.io/posebridge/`.

If you want the shorter `https://<username>.github.io/` address, create a repository named exactly `<username>.github.io` instead.

## Before publishing

- Replace the disabled **Code** button in `index.html` with the final code repository URL once public.
- Add personal homepage links to the author names if desired.
- For long-term robustness, download the four paper figures currently loaded from arXiv and place them under `assets/`, then change the image paths to local files.
